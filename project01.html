Project 1: Getting to Know You

So I made a Lego guy with a sword and shield. I remember building a lot of these types of guys when I was younger, mainly because of watching Power Rangers. I tried to bend the legs using a different piece, but the Lego guy kept falling over, so I switched to straight pieces for the legs. I also added a back wing part to support the sword and shield on the front. I wanted to try to build something more complicated, but it has been a long time since I messed with Legos, and I have not used Technic pieces at all. I did manage to make the guy swing using the Technic pieces, though.
